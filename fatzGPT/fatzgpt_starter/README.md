# fatzGPT — Flutter starter

## Menjalankan
1. Install Flutter SDK dan Android Studio.
2. Ekstrak folder proyek.
3. Jalankan `flutter pub get`.
4. Jalankan `flutter run` pada perangkat Android atau emulator.

## Status starter
- Full-screen dark futuristic interface.
- Animated purple orb drawn with Flutter CustomPainter.
- Chat composer and local message display.
- API Manager screen UI with provider selector.

## Belum diintegrasikan
- Panggilan LLM sungguhan.
- Penyimpanan API key terenkripsi.
- Backend/proxy untuk melindungi kredensial.
- Speech-to-text dan text-to-speech.

API key tidak boleh ditanam langsung di source code atau APK produksi.
